## Commands

- `npm run dev` — local dev server.
- `npm run build` — static export to `out/` (see "Static export" below). This is
  also the deploy build.
- `npm run lint` / `npm run lint:fix` — ESLint (flat config, `eslint.config.mjs`).
- `npm run format:check` / `npm run format` — Prettier. Prettier also runs _as an
  ESLint rule_ (`prettier/prettier: error`), so a formatting slip fails lint too.
- `npm run typecheck` — `tsc --noEmit`.
- `npm run validate` — lint + format:check + typecheck + build + `npm audit`; the
  same gates CI runs. `npm run validate:fix` applies the autofixable ones.

There is no test suite.

## Architecture

A private, phone-first PWA for daily checklists. No accounts, no backend, no
network calls — everything lives in the browser.

- **Static export + basePath.** `next.config.ts` sets `output: "export"` and
  `basePath: "/routines"` (deployed to GitHub Pages under `/routines`). There is
  no server at runtime: no route handlers, no server actions, no dynamic SSR.
  Every absolute in-app URL (service worker registration, manifest, icons) must
  include the `/routines` prefix.

- **State = localStorage only.** `src/lib/storage.ts` is the single source of
  truth, persisting one JSON blob under the `routines-data` key. All reads go
  through `normalizeState`, which **resets each routine's checked steps when its
  `lastResetDate` is not today** — the daily-reset behavior is a side effect of
  reading, not a scheduled job. Every accessor is SSR-guarded
  (`typeof window === "undefined"` returns empty data), so first render is empty
  and real data appears after mount. Types are in `src/types.ts`.

- **Routing pattern.** `src/app/**/page.tsx` files are thin server wrappers; the
  real screens are the `*Route` client components in
  `src/app/routine/_components/routine-routes.tsx`. Those load the relevant
  `Routine` from storage into local state inside `useEffect`/`startTransition`,
  and read the target id from the `?id=` search param. Any route using
  `useSearchParams` must stay wrapped in `<Suspense>` (required for the static
  export build to succeed). Navigation is plain `router.push` between `/`,
  `/routine?id=`, `/routine/edit?id=`, `/new`, and `/settings`.

- **i18n (next-intl) is doubly wrapped.** `src/i18n/request.ts` hard-codes
  `locale: "pl"` for the server config, and `layout.tsx` also wraps the tree in a
  server `NextIntlClientProvider` (pl). On top of that,
  `src/components/i18n-provider.tsx` adds a _client_ provider with a runtime
  pl/en toggle (`useI18n`). Message catalogs are `messages/pl.json` and
  `messages/en.json` — keep both in sync when adding keys.

- **Mobile gate + PWA.** `src/components/mobile-gate.tsx` renders the app for
  mobile viewports and a "desktop not supported" message otherwise, and registers
  the service worker (`public/sw.js`).

- **UI stack.** shadcn (`base-nova` style, see `components.json`) built on
  `@base-ui/react` — primitives live in `src/components/ui`. Tailwind v4 (via
  `@tailwindcss/postcss`) with design tokens in `src/app/globals.css`; icons from
  `lucide-react`. Step reordering uses `@dnd-kit`.
